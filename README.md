# Hajime Studio landing page

Public landing page for **Hajime Studio** (好嚟喇製作公司).

Stack: Vite + React + TypeScript.

## Local

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173

## Build

```bash
npm run build
npm run preview
```

## Palette

- Paper cream `#F6F1EA`
- Ink `#141414`
- Studio red `#B61231`
